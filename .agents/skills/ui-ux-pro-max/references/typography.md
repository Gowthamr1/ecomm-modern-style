# Typography Reference

Typography establishes visual rhythm, reading speed, and emotional tone.

## Modular Scales
- **Perfect Fourth (1.333)**: Recommended for editorial, marketing, and high-impact hero pages.
- **Major Third (1.250)**: Recommended for SaaS dashboards, data-dense interfaces, and web apps.
- **Minor Third (1.200)**: Recommended for compact mobile screens and high-density lists.

## Recommended Font Pairings

### 1. Modern Geometric / Clean Tech
- **Display / Heading**: `Geist Sans`, `Plus Jakarta Sans`, or `Inter` (Font weight 600-700, tracking -0.02em)
- **Body**: `Inter` or `system-ui` (Font weight 400-500, leading 1.6)
- **Monospace / Code**: `JetBrains Mono` or `Geist Mono`

### 2. Editorial E-Commerce / Refined Luxury
- **Display / Heading**: `Playfair Display`, `Fraunces`, or `Cormorant Garamond` (Font weight 500-600)
- **Body**: `Plus Jakarta Sans` or `Inter` (Font weight 400, leading 1.65)
- **Micro-Labels**: Uppercase geometric sans, tracking +0.08em

# Anti-Patterns Reference

1. **The Gray-on-Gray Trap**: Using light-gray text (`#94A3B8`) on a white background for critical instructions. Fails WCAG AA.
2. **Generic AI Violet Cliché**: Defaulting to the same purple-to-blue gradient on every hero section.
3. **Card Inception**: Wrapping cards inside cards inside cards with borders on every layer. Use whitespace and background shifts for containment instead.
4. **Neglected Empty & Loading States**: Creating designs that look good only with dummy data, with no skeletons, error banners, or empty state illustrations.
5. **Tiny Click Targets**: Mobile buttons and interactive elements under 44x44px.
