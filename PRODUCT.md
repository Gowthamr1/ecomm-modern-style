# Forma — Product Vision & Multi-Platform Strategy

## 1. Product Overview
Forma is an editorial e-commerce platform for considered everyday physical objects (audio, timepieces, workspace furniture, ceramics, lighting). It embodies the ethos of *"Choose fewer things, use them longer."*

## 2. Multi-Platform Targets

| Platform | Primary Use Case | UX & Ergonomic Priorities |
| :--- | :--- | :--- |
| **Android / Mobile** | One-thumb browsing, fast checkout on the go | Bottom navigation bar, sticky bottom checkout sheets, safe-area padding, swipe gestures, tap targets >= 48px. |
| **Responsive Web** | Deep catalog exploration, editorial reading | High-impact hero layout, rich imagery, responsive bento grids, fluid typography, dark/light theme switching. |
| **Windows / Desktop App** | Power shopping, order tracking, admin management | Wide viewport optimization, Ctrl+K command palette, dense list/grid toggles, keyboard shortcuts, windowed title bar integration. |

## 3. Core Jobs to Be Done (JTBD)
1. **Discover**: Browse collections organized by mood and material rather than generic categories.
2. **Appreciate Details**: Inspect high-resolution photography, dimension specs, acoustic/craft notes.
3. **Seamless Purchase**: Add to bag in 1 tap, review transparent totals with zero hidden fees.
4. **Track & Retain**: View real-time order progression and invoice receipts on any device.

## 4. Key Metrics
- Time-to-first-browse < 1.5s
- Mobile checkout completion rate >= 85%
- Accessibility compliance: 100% WCAG AA
